Contributing

Thank you for your interest in contributing to google-hashcode-judge!

Contributions are welcome, especially bug fixes and improvements to existing validation scripts and tests.

How to Contribute
Fork this repository on GitHub.
Clone your fork and create a branch for your changes.
Make your changes and test them.
Commit and push your changes to your fork.
Open a pull request against the original repository, explaining what you changed and why.
What You Can Contribute
Fix bugs or incorrect validation rules in existing scripts.
Improve error messages and input/output validation.
Fix or improve tests, including tests that verify official example scores.
Improve existing documentation.

Please note: Contributions must be limited to existing files. Do not add new validator scripts, tests, or other files for problems that are not already covered by the repository.

Guidelines
Follow the existing code structure and conventions.
Use only the Python standard library; do not introduce external dependencies.
Ensure validation behavior and official example scores remain correct.
Keep changes focused and explain the purpose of your pull request clearly.

All contributions are subject to review before being merged.

Thank you for helping improve the project!
