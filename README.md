# google-hashcode-judge
Judge system for every Google Hash Code problem, 2014–2022. One standalone Python validator per problem, all following the same template: same command line, strict validation with clear error messages, and the official example score reproduced as a test. Standard library only.

[EXISTING_JUDGES.md](EXISTING_JUDGES.md) lists the judges that other people published before this project. We analyzed each of them before we wrote our judges.
